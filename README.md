# Dynamic Island для Windows — форк

Остров в духе iPhone у верхнего края экрана: показывает, что играет, громкость, таймер и системные события, а по клику раскрывается в плеер.

Этот репозиторий является форком оригинального проекта [mihailkotovski/DynamicIsland](https://github.com/mihailkotovski/DynamicIsland). Оригинальная идея, большая часть интерфейса и базовая архитектура сохранены, а дополнительные изменения описаны ниже.

## Что добавлено в этом форке

- поддержка пользовательских синхронных текстов из `.lrc`, `.yaml` и `.yml`;
- выбор папки с текстами в разделе **Настройки → Папка с LRC**;
- поиск текстов во вложенных папках;
- приоритет локальных текстов над LRCLIB;
- поддержка YAML-формата с `lines[].start_ms` и `lines[].text`;
- сопоставление YAML по имени файла или по `metadata.title` и `metadata.artist`;
- захват приложения в OBS через обычный источник **Захват окна**;
- подержка OBS через аргумент --obs;
- режим изменения положения острова с перемещением между мониторами;
- контур и анимация при перемещении;
- встроенная иконка приложения;
- сохранение выбранного аудиоустройства при переключении режима захвата.

## Что умеет

- **Музыка.** Обложка, название и эквалайзер для любого приложения с системной медиасессией (Spotify, браузер, Яндекс Музыка и другие). Цвет полосок берётся из обложки, и в тот же цвет окрашивается светлый ободок острова.
- **Текст песни.** Синхронные строки с LRCLIB или из локальных LRC/YAML-файлов прямо в компактном острове.
- **Плеер.** По клику открываются большая обложка, перемотка, кнопки назад/пауза/вперёд и текст песни.
- **Несколько источников.** Если музыка играет сразу в нескольких приложениях, `Ctrl + колесо` переключает их по кругу.
- **Живой спектр.** Полоски считаются по реальному выводу звука через WASAPI loopback.
- **Громкость.** Колесо мыши над островом меняет громкость. В раскрытом плеере можно управлять громкостью играющего приложения.
- **Таймер.** Таймер от 1 до 99 минут с кольцом, анимацией последних секунд и уведомлением по окончании.
- **Полка для файлов.** Файлы можно перетаскивать на остров и открывать их из полки.
- **Заряд наушников.** Показывается заряд Bluetooth-наушников, если его передаёт Windows.
- **Уведомления.** Подключение зарядки, смена аудиоустройства, Wi-Fi/Ethernet, VPN и режим «Не беспокоить».
- **Не мешает.** Остров скрывается во время полноэкранных приложений, не появляется в Alt-Tab и не забирает фокус.
- **Настройки.** Тексты песен, эффекты текста, цветной ободок, громкость приложения, сетевые уведомления, скрытие на полном экране и автозапуск.
- **Оформление.** Размер острова, отступ от верхнего края, пульс ободка и акцентный цвет.

## Тексты песен

Папка с пользовательскими текстами выбирается в приложении:

**Настройки → Папка с LRC**

Приложение ищет файлы в выбранной папке и во всех вложенных папках. Если локальный файл найден, он используется вместо онлайн-результата LRCLIB.

Поддерживаются имена:

```text
Исполнитель - Название.lrc
Название.lrc
Исполнитель - Название.yaml
Название.yml
```

### Формат LRC

```text
[00:10.070] Первая строка
[00:12.780] Вторая строка
```

### Формат YAML

Поддерживается формат с массивом `lines` и временными метками в миллисекундах:

```yaml
version: '1.0'
metadata:
  title: Название песни
  artist: Исполнитель
  album: Название песни
  duration_ms: 115000

lines:
- text: Первая строка
  start_ms: 10070
  end_ms: 12780
- text: Вторая строка
  start_ms: 12780
  end_ms: 15390
```

Для поиска используются имя файла, `metadata.title` и `metadata.artist`. Для синхронизации используется `start_ms`; поле `end_ms` может присутствовать, но не является обязательным.

## Добавление в OBS

1. Запустите `DynamicIsland.exe`.
2. В OBS добавьте источник **Захват окна**.
3. Выберите окно Dynamic Island.
4. При необходимости отключите захват курсора.

Browser Source, Browser Socket и отдельный веб-сервер для отображения виджета не требуются.

## Управление

| Действие | Результат |
| --- | --- |
| Клик | Раскрыть плеер или таймер, повторный клик — свернуть |
| Клик по обложке в плеере | Открыть приложение, в котором играет музыка |
| Правый клик | Открыть меню |
| Клик колесом | Спрятать остров на 5 секунд |
| Колесо мыши | Изменить громкость |
| `Ctrl + колесо` | Переключить приложение с музыкой |
| Перетаскивание файлов на остров | Положить файлы на полку |
| Перетаскивание файла с полки | Скопировать файл в выбранное место |
| Клик по звонящему таймеру | Выключить звонок |
| Режим «Изменить положение» | Переместить остров и выбрать монитор |

## Скачать и запустить

Готовый EXE можно собрать командой из раздела ниже. После публикации файл находится здесь:

```text
publish\DynamicIsland.exe
```

Установка не требуется. Приложение рассчитано на 64-битную Windows 10 2004 (сборка 19041) и новее, а также Windows 11.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Обычная сборка:

```powershell
dotnet build DynamicIsland.csproj --configuration Release
```

Запуск из исходников:

```powershell
dotnet run --configuration Release
```

Один автономный EXE для Windows x64:

```powershell
dotnet publish DynamicIsland.csproj `
  --configuration Release `
  --runtime win-x64 `
  --self-contained true `
  --property:PublishSingleFile=true `
  --property:IncludeNativeLibrariesForSelfExtract=true `
  --property:EnableCompressionInSingleFile=true `
  --property:DebugType=none `
  --output publish
```

Промежуточные каталоги `bin` и `obj` можно удалить после публикации — они не нужны для запуска EXE.

## Зависимости

- .NET 8 и WPF;
- Windows Forms для выбора папки и работы с мониторами;
- `YamlDotNet` для разбора YAML-файлов;
- Windows API для мультимедиа, громкости, уведомлений и захвата звука.

## Шрифты и иконка

Остров использует шрифты SF Pro из папки [Fonts](Fonts/), которые встраиваются в приложение при сборке. Если файлы шрифтов недоступны, используется Segoe UI.

Иконка приложения находится в `Resources\AppIcon.ico`.

## Отладка

```powershell
DynamicIsland.exe --view MediaBig
DynamicIsland.exe --timer 90
```

`--view` закрепляет состояние острова (`Idle`, `Media`, `Timer`, `Volume`, `Charge`, `Toast`, `Notice`, `MediaBig`, `IdleBig`, `TimerBig`, `TimerSet`, `Menu`, `Settings`, `Look`), а `--timer` запускает отсчёт на указанное число секунд.

Необработанные ошибки записываются в `%TEMP%\DynamicIsland.log`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `MainWindow.xaml(.cs)` | Состояния острова, меню, настройки, перемещение и анимации |

| `Resources\AppIcon.ico` | Иконка приложения |
| `Fonts\` | Шрифты интерфейса |

## Конфиденциальность

При включённом онлайн-поиске приложение отправляет на `lrclib.net` название трека и исполнителя. Локальные LRC/YAML-файлы обрабатываются на компьютере и никуда не загружаются.

Автозапуск хранится в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Остальные настройки, включая папку с текстами, хранятся в `HKCU\Software\DynamicIsland`.
